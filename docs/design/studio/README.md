# Studio UI 시안 소스

2026-10-22 사용자와 확정한 Studio 시안이다(테스트 실행 화면과 사이드바 재구성은 2026-10-23 확정)(시안 도구의 "TorchLauncher Studio UI 시안" 캔버스에서 복사). 런처 시안과 같은 색 토큰을 쓴다.

- `*.dc.html`은 시안 도구용 파일이다. 브라우저에서 단독으로 열 수 없다(`support.js`가 없음). **마크업, 문구, 클래스, CSS를 읽는 참고 자료**로만 쓴다.
- `studio.css`가 공용 스타일(색 토큰, 창/사이드바/카드/버튼/알림 컴포넌트)이다. 구현에서는 앱의 CSS로 옮기되 토큰 이름과 값을 유지한다.
- 시안의 `src="/_blob/..."` 이미지는 모두 `assets/branding/icon.png`(레드스톤 토치)다.
- 서버 이름, 경로, 파일 수/크기, 시각, 주소는 **샘플 데이터**다. 실제 값은 프로젝트와 Studio 상태에서 가져온다.
- 창 제목 표시줄(최소화·최대화·닫기)은 시안용으로 그렸다. 구현은 OS 기본 창 틀을 쓰고 창 제목·아이콘만 반영한다.
- 글꼴: 시안은 Google Fonts(Noto Sans KR 등)를 불러오지만 **앱은 외부 네트워크로 글꼴을 받지 않는다.** 런처와 같은 번들 글꼴(본문 Pretendard Variable, 워드마크 Pixelify Sans)을 쓴다.
- 시안의 링크(`href="Files.dc.html"` 등)는 화면 간 이동을 보여주는 것일 뿐이다. 실제 라우팅/상태 전환은 구현이 정한다.
- 테스트 실행(로그인, 준비, 실행, 결과)과 게임 구성/플레이어 설정 분리는 시안으로 확정했고 구현은 TESTRUN-UI-01에서 한다([작업서](../../studio-test-run-task.md)).

| 파일 | 화면 |
| --- | --- |
| Splash | 시작 애니메이션 |
| Main | 시작 화면(프로젝트 없음) |
| DialogUnsaved | 저장하지 않은 변경 확인 |
| Overview | 개요(업데이트 상황) |
| Server | 서버 정보 |
| Brand | 브랜딩(플레이어가 보는 런처 미리보기, 아이콘/이름/배경 변경) |
| SettingsMods, SettingsPacks, SettingsShaders | **게임 구성**: 모드 설정(설정 파일 목록과 항목별 정책) / 리소스팩(추가·순서·고정) / 셰이더(팩 추가·선택·세부 옵션) |
| Files | **게임 구성**: 파일(마지막 배포와 비교) |
| TestStart | **테스트 실행**: 시작 전(환경 요약, 계정 로그인 필요) |
| TestLogin | 테스트 실행: Microsoft 로그인(코드 입력, 앱 안 모달) |
| TestPreparing, TestFailed | 테스트 실행: 게임 준비 중(단계·진행률·로그) / 준비 실패(실패 단계, 다시 시도) |
| TestRunning, DialogStopTest | 테스트 실행: 게임 실행 중(실시간 로그, 종료 버튼) / 종료 확인(앱 안 모달) |
| TestResultProblems, TestResultOk | 테스트 결과: 문제 발견(오류·경고 카드, 근거 로그 줄, 모드 목록) / 문제 없음(호환 보증 아님 문구, 기록된 단축키와 옵션) |
| DialogReset | 테스트 폴더 초기화 확인(앱 안 모달) |
| SettingsEmpty, Settings | **플레이어 설정**: 단축키 · 옵션 가져오기 전(테스트 결과 / options.txt 선택) / 가져온 후(가져온 곳 선택, 일괄 변경) |
| DialogPreset | options.txt 파일 가져오기(폴더 또는 파일 선택, 보조 경로) |
| DeployChanged, DeployReady | 배포: 변경됨(다시 만들기 필요) / 최신 상태 |
| Export, ExportBlocked, ExportDone | 런처 내보내기 / 환경 불일치로 차단 / 완료 |

사이드바 순서(확정): 개요, 서버 정보, 브랜딩 / **게임 구성**(모드 설정, 리소스팩, 셰이더, 파일) / **테스트**(테스트 실행) / **플레이어 설정**(단축키 · 옵션) / **배포**(배포, 내보내기). 메뉴 높이는 38px, 그룹 이름은 `.mg`이다.

결정 사항(2026-10-23, 구현에 반영할 것)
- 테스트 페이지는 설명 문구를 최소화한다. 헤더 설명은 "테스트 실행에서 기록한 단축키와 옵션은 플레이어 설정에서 불러올 수 있습니다."
- 게임 실행 중에는 로그와 종료 버튼만 둔다. 종료 버튼은 앱 안 확인 모달을 거친다(네이티브 확인창 금지).
- 문제 없음 결과의 보조 문구는 "모든 모드가 문제 없이 동작함을 보장하지는 않습니다."이다.
- 단축키 · 옵션의 값은 사용자가 그 화면에서 가져온다. 가져올 곳은 "테스트 실행 결과"와 "options.txt 파일" 중 선택한다. 테스트 종료가 자동으로 값을 채우지 않는다.
- "모드가 만든 설정 파일" 안내는 모드 목록 카드에 두고, 단축키와 옵션 카드에는 넣지 않는다.
