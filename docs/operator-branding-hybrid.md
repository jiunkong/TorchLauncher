# 운영자 브랜딩 — 동봉 초기본 + 원격 갱신

2026-10-23 사용자 승인: 내보내기에는 초기 이미지를 포함하고 torchpack에도 이미지를 넣는다.
배포 파일을 읽어 이미지 변경이 확인되면 해당 이미지만 받는다. 기존 이미지를 유지하다 검증된 새 이미지로 전환한다.
이는 앞선 단독 동봉 권고를 대체한다. 공통 exe 재패키징/아이콘 변경은 하지 않는다.

## 제품 동작

- 최초에는 JSON 옆 동봉 이미지를 표시한다. 이후에는 해당 프로파일에 맞는 마지막 검증 캐시를 우선한다.
  동봉/캐시가 없으면 기본 레드스톤 토치·기본 scene을 쓴다. 잘못된 선택 자산은 읽지 않고 기본/이전 표시를 유지한다.
- 시작 시 원격 배포 메타데이터를 비동기로 확인하며 게임 실행 준비 중 읽은 최신 메타데이터도 갱신에 활용한다.
  반복 폴링은 하지 않는다. 같은 해시의 이미지는 다시 받지 않는다. 신규 검증/디코드까지 기존 표시를 유지한다.
- 브랜딩은 게임 데이터/설치 소유권과 분리한다. 이미지 실패가 로그인/게임 실행을 실패시키지 않아야 한다.
  잘못된 전체 배포 인덱스나 기존 게임 동기화의 안전 경계를 약화하지 않는다.
- 원격 미지원(기존 배포)과 원격의 명시적 이미지 제거를 구분한다. 전자는 기존 표시 유지, 후자는 기본 이미지로 전환한다.
- 메뉴 아이콘과 홈 배경은 디코드 후 짧은 교차 페이드, reduced-motion에서는 즉시 전환한다.
  OS 창 아이콘은 검증본으로 교체하며 OS의 페이드까지 보장하지 않는다.
- 앱 이름은 창 제목/메뉴 이름만 적용한다. app.setName/appId/userData/인증 캐시/홈 서버 이름은 유지한다.
  시작 애니메이션은 항상 TorchLauncher, exe 아이콘 고정. 단일 서버·한국어 i18n·선택/끌기 정책 유지.
- Studio가 선택한 동일 이미지 스냅샷을 로컬 내보내기와 torchpack 양쪽에 넣는다.
  현재 폴더 내보내기에 먼저 적용할 수 있으나 사용자에게 ZIP을 이미 생성한 것처럼 안내하지 않는다.
  자동 ZIP은 기존 Studio 개편 작업과 조정하며 새 의존성/lockfile 변경은 별도 승인한다.

## 검증·캐시 원칙

이미지 파일 경로·길이·형식·SHA-256·실제 디코드/픽셀 수를 검사한다. 로컬 경로는 실제 프로파일 JSON의
디렉터리를 기준으로 하고 symlink/hardlink/상위 경로 이탈을 거부한다. 원격은 기존 검증된 Range reader를 사용한다.
아이콘 PNG 최대 1MiB/512px, 배경 PNG/JPEG 최대 8MiB/3840×2160(픽셀 상한 포함)을 초기 상한으로 제안한다.
캐시는 게임 루트 밖에 서버 ID/프로파일 기준으로 격리하고 원자적으로 기록한다. 불완전/손상 캐시를 표시하지 않는다.
프로파일 변경/종료 후 늦은 응답이 이전 이미지를 덮어쓰지 않게 한다. 개인 URL/경로·원본 오류는 renderer에 내보내지 않는다.
8MiB 배경을 매 상태 이벤트마다 복사하지 않도록 전달 경로를 설계한다. 해시는 진위 서명을 대체하지 않는다.

## BRAND-CORE-01 기술 검토 승인 (2026-10-23)

- 프로파일 v1에 선택적 branding(appName 및 동봉 자산 path/sha256/length/mediaType)을 추가한다.
- 브랜딩이 있는 torchpack은 v1.1을 사용한다. 기존 일반 pack 출력은 v1.0이며 새 reader는 둘 다 읽는다.
  기존 구버전 런처는 새 형식을 거부하므로 새 브랜딩 기능 사용 시 런처 갱신이 필요하다.
- 게임 files 다음 icon/background payload를 연속 배치하고 전체 경계/길이/중첩을 검증한다.
  원격 branding 또는 역할 생략은 유지, 명시적 null은 제거다. 원격 앱 이름 변경은 하지 않는다.
- writer는 제한된 이미지 bytes를 작업 시작 시 스냅샷으로 고정하며 reader는 별도 stageBrandingAsset을 제공한다.
  기존 DeploymentReader 소비자/테스트의 호환성을 유지한다. 실제 이미지 디코드는 앱 단계에서 검사한다.
- 현재는 core 구현 중이며 런처/Studio 연결과 Windows 확인은 아직 완료하지 않았다.
