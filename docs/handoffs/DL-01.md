## Source contract

`packages/core/src/download/source/index.ts` defines the internal `DownloadSource` contract and `createDownloadSource(url, options)`. Sources expose `kind`, a stable opaque `sourceId`, `generation`, a defensive snapshot copy, `getRange(range, options)`, and `reset()`. Range results include the DL-02 `RangeResponse` plus source ID and generation. Generic HTTPS links wrap the existing `HttpRangeClient`; recognized Google Drive public file links use the Drive resolver and the same range client.

When a transfer detects a changed resource, or Drive returns an expired-address status (401, 403, 404, or 410), the source aborts outstanding work and throws `SourceRestartRequiredError`. It never silently resolves a new URL and continues old ranges. Callers must discard pending work, call `reset()`, and reread the index before requesting ranges in the new generation.

## Drive handling and attribution

Public Drive file IDs are accepted from `id` query links, `/file/d/<id>/view` links, and the common `docs.google.com` and `drive.usercontent.google.com` forms. Confirmation `href`, `#download-form` hidden fields, embedded `downloadUrl`, and Drive error messages are adapted from gdown. Page reads default to 2 MiB with a configurable 16 MiB ceiling; redirects default to five and are bounded at ten. Resolution uses only HTTPS Google Drive hosts and an in-memory anonymous cookie jar scoped to Google-owned domains. Range redirects are checked against the same host allowlist. No account authentication or persistent cookies are included.

The adaptation and MIT notice are recorded in `third-party/gdown/`. Source commit: `fba3f9aa27b76fabfee0502f21a1988678bfd710` (gdown v6.1.0). Upstream areas adapted: `gdown/parse_url.py` file ID parsing and `gdown/download.py::get_url_from_gdrive_confirmation`.

## Limitations

- Folder downloads and Google Docs/Sheets/Slides export behavior are out of scope; this source handles single-file range transfers.
- A URL that expires or a resource that changes requires an explicit generation reset and index reread; no transparent continuation is attempted.
- The module is available by internal source path; package export maps were not changed.
